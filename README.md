# Student Issue Intelligence & Resolution System

A Flask + MySQL + Machine Learning project for intelligent student issue management.

## Planned versions

1. Foundation — Login + DB + complaint submission
2. Management — Admin dashboard + department + status
3. Intelligence — Classification + priority
4. Advanced AI — Duplicate detection + resolution prediction
5. Research — Model comparison + metrics + charts
6. Final — UI polish + testing + report + PPT + GitHub

- Flask
- MySQL
- HTML/CSS/Bootstrap
- scikit-learn

- Chart.js
